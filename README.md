# دفتر الديون

وكيل ذكي يفهم كلام صاحب المحل باللهجة العراقية، ويسجل الديون والتسديدات بدل الدفتر الورقي.

```
إنت>    سجل على ابو علي 25 الف
الوكيل> تمام، سجلت على أبو علي 25,000 دينار. صار عليه 40,000 دينار.
```

---

## التشغيل على ويندوز (أول مرة)

### 1. نصّب Python
نزّله من [python.org](https://www.python.org/downloads/) (نسخة 3.11 أو أحدث).
**مهم:** وقت التنصيب أشّر على **Add python.exe to PATH**.

حتى تتأكد، افتح PowerShell واكتب:
```
py --version
```
لازم يطلعلك رقم مثل `Python 3.14.0`.

### 2. نزّل المشروع
من GitHub: **Code ← Download ZIP**، وفك الضغط بأي مكان.

### 3. سوّي ملف المفتاح `.env`
- خذ مفتاح Gemini مجاني من [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
- بمجلد المشروع، افتح PowerShell (اكتب `powershell` بشريط العنوان فوگ واضغط Enter)، والصق هذا الأمر بعد ما تبدّل `مفتاحك_هنا`:
  ```
  Set-Content -Path .env -Encoding ascii -Value "LLM_PROVIDER=gemini`nGEMINI_API_KEY=مفتاحك_هنا"
  ```
- تأكد إن ملف `.env` حجمه مو 0 KB.

باقي الإعدادات الاختيارية موجودة بملف `.env.example`.

### 4. شغّل
**دبل كليك على `start.bat`.**
أول مرة ينصّب المكتبات (دقيقة أو دقيقتين)، وبعدين تنفتح الواجهة بالمتصفح وحدها على `http://127.0.0.1:8000`.

للإيقاف: سد النافذة السوده، أو اضغط بيها Ctrl+C.

## شلون أستعمله

**الواجهة:** يمين المحادثة، ويسار جدول المدينين يتحدث بعد كل رسالة. تحت كل رد زر **"شنو سوّى الوكيل؟"** يبين الأدوات اللي استدعاها والنتائج.

**أمثلة رسائل:**

| الرسالة | شنو يسوي |
|---|---|
| سجل على ابو علي 25 الف | دين 25,000 دينار |
| أبو علي دفع عشرة | تسديد 10,000 (الرقم الصغير = آلاف، ويگول التفسير) |
| ابو علي جاب 20 دولار | تسديد 20 دولار، كل عملة رصيدها لحالها |
| سجل على ابو علي ربع مليون | دين 250,000 |
| سجل على ابو علي 3 مليون | يسأل "متأكد؟" قبل ما يسجل (المبالغ الكبيرة) |
| شكد باقي على ابو علي؟ | يجاوب بدون ما يسجل شي |
| منو أكثر واحد عليه دين؟ | قائمة المدينين والمجموع |
| شطب آخر وحدة غلط | يلغي آخر قيد (ما ينمسح، يتعلّم كملغي) |

**قواعد يمشي عليها:** ما يخترع زبون (إذا الاسم مو موجود يسألك "أضيفه؟")، وإذا أكثر من زبون بنفس الاسم يسأل "تقصد منو؟"، وما يخمّن مبلغ.

البيانات محفوظة بملف `debt.db` بمجلد المشروع. خلّي منه نسخة احتياط.

## حدود Gemini المجاني

- كل نموذج: **20 طلب باليوم** و**5 بالدقيقة**. كل رسالة تاخذ 2 أو 3 طلبات.
- البرنامج **يبدّل النموذج وحده** لما وحد تخلص حصته أو يكون عليه ضغط (القائمة بـ `GEMINI_FALLBACK_MODELS`)، فتوصل تقريبًا لـ 30 أو 40 رسالة باليوم.
- إذا تريد تستعمله بالمحل كل يوم، فعّل الدفع بحساب Google AI Studio.
- تگدر تستعمل Claude بداله: `LLM_PROVIDER=anthropic` و `ANTHROPIC_API_KEY=...` بملف `.env`.

## التقييم

13 رسالة عراقية حقيقية بـ `eval/cases.json`. كل حالة تشتغل على قاعدة بيانات نظيفة إلها بيانات بداية، والتقييم يفحص **قاعدة البيانات بعد الرسالة** (هل انسجل القيد الصحيح؟ هل ما انسجل شي لما لازم يسأل؟) + الأدوات اللي انستدعت + الرد.

```
python eval/run_eval.py          # كل الحالات
python eval/run_eval.py 1 3 7    # حالات معينة
```

**آخر نتيجة: 13/13 (100%)**، تشغيلة وحدة بتاريخ 2026-10-10 على Gemini المجاني. البرنامج بدّل النماذج وحده بنص التشغيلة لما خلصت حصصها، وخلص على `gemini-3.5-flash-lite`. (من هسه، التقييم يسجل النموذج اللي جاوب كل حالة.)

| # | الرسالة | المتوقع | النتيجة |
|---|---|---|---|
| 1 | سجل على ابو علي 25 الف | دين 25000 | ✅ |
| 2 | أبو علي دفع عشرة | تسديد 10000 + ذكر التفسير | ✅ |
| 3 | شكد باقي على ابو علي؟ | 15000 بدون قيد | ✅ |

## مشاكل معروفة وحلولها

| المشكلة | الحل |
|---|---|
| `py is not recognized` | نصّب Python وأشّر Add to PATH، وسد PowerShell وافتحه من جديد |
| `No such file or directory: 'requirements.txt'` | الطرفية مو بمجلد المشروع. افتحها من شريط العنوان داخل المجلد |
| `ResolutionImpossible` وقت التنصيب | غالبًا انقطاع نت. عيد الأمر |
| "المنفذ 8000 مشغول" | نسخة قديمة شغالة: `taskkill /F /IM python.exe /IM py.exe` |
| "خلصت حصة اليوم" | انتظر لباچر، أو فعّل الدفع بـ Google AI Studio |
